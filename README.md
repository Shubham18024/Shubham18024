### 🚀 Featured Project: [Python Mathematical Animation](https://github.com/Shubham18024/Python-Mathematical-Animation)

A computational project focused on translating pure mathematics into dynamic visual systems.

* **Tech Stack:** Python 3.12, NumPy, Matplotlib, Jupyter, and `uv`.
* **Key Features:** 
  * 2D & 3D parametric motion
  * Complex rotation matrices & linear transformations
  * Coordinate geometry and camera kinematics
  * Rendering rigid bodies (triangles, squares, cubes) and complex topological manifolds.
